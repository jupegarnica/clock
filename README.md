## Clock

A real-time color clock demo built with Astro, React & styled-components.

- Background color = `#HHMMSS` from current time
- Shows time in hex, RGB, HSL, and nearest CSS named color

### Quick start
```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # output to dist/
npm run preview   # serve build with Deno
```
